# AMBA AXI 协议规范文档

本目录按 ARM IHI0022 (AMBA AXI and ACE Protocol Specification) 的章节结构组织协议规范文档。

## 文档结构

| Part | 标题 | 内容 |
|------|------|------|
| Part A | AXI4 基础协议 | 通道定义、信号描述、事务属性、排序模型、原子访问 |
| Part B | 附录 | 低功耗接口、时序参数 |
| Part C | AXI4-Lite | 精简协议规范 |
| Part D | ACE 缓存一致性 | Snoop 通道、MOESI 状态、Barrier、DVM |
| Part E | AMBA 5 新特性 | 原子事务、Cache Stashing、数据保护 |
| Part F | ACE5 协议族 | ACE5、ACE5-Lite、ACE5-LiteDVM、ACE5-LiteACP |

## 参考规范版本

- ARM IHI 0022J (2023年3月)
- ARM IHI 0051A (AXI4-Stream)
