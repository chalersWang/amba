# Part A: AXI4 基础协议

本部分涵盖所有 AXI 接口共用的基础协议规范。

## 章节列表

| 章节 | 标题 | 关键内容 |
|------|------|----------|
| A1 | 介绍 | 架构概述、通道定义、互连概念、术语 |
| A2 | 信号描述 | 5 通道信号、全局信号（时钟/复位/唤醒） |
| A3 | 单接口需求 | VALID/READY 握手、时钟复位、依赖关系 |
| A4 | 事务属性 | Burst 类型/长度/大小、传输地址、写选通、非对齐传输 |
| A5 | 事务标识符 | ID 标签、乱序完成 |
| A6 | 排序模型 | 读写排序规则、事务交织 |
| A7 | 原子访问 | Exclusive 独占访问、Locked 锁定访问 |
| A8 | 附加信号 | QoS、区域标识、保护单元支持 |
| A9 | 互操作性 | 默认信号、跨接口兼容规则 |
