# D1: ACE 概述 (ACE Overview)

## 1. 系统级一致性

- ACE 在 AXI4 基础上增加硬件缓存一致性
- 适用场景：多核 CPU 集群、GPU 一致性、异构计算
- MOESI 缓存状态模型

## 2. 缓存模型

| 状态 | 含义 |
|------|------|
| M (Modified) | 缓存行被修改，与内存不同 |
| O (Owned) | 缓存行被拥有，与其他缓存共享 |
| E (Exclusive) | 缓存行独占，与内存相同 |
| S (Shared) | 缓存行被多个缓存共享 |
| I (Invalid) | 缓存行无效 |

- Passive / Active 错误响应
