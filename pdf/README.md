# AMBA 官方协议规范 PDF

本目录收录 ARM 官方 AMBA 协议规范的 PDF，覆盖各协议族最新版本。

## 文件索引

| 文件 | 协议 | ARM 文档号 | 内容 |
|------|------|-----------|------|
| `AMBA_APB_protocol.pdf` | APB4 | IHI 0024 | Advanced Peripheral Bus（外设总线） |
| `AMBA_AHB_protocol.pdf` | AHB5 / AHB-Lite | IHI 0033 | Advanced High-performance Bus（高性能总线） |
| `AMBA_AXI_and_ACE_protocol.pdf` | AXI3/AXI4 + ACE/ACE-Lite | IHI 0022 | AXI and ACE Protocol |
| `AMBA_AXI5_and_ACE5_protocol.pdf` | AXI5 + ACE5 | IHI 0022 | AXI and ACE Protocol（最新版） |
| `AMBA_AXI4_Stream_protocol.pdf` | AXI4-Stream | IHI 0051 | 单向流式接口 |
| `AMBA_ATB_protocol.pdf` | ATB | IHI 0032 | Advanced Trace Bus（追踪总线） |
| `AMBA_CHI_protocol.pdf` | CHI | IHI 0050 | Coherent Hub Interface（一致性集线器接口） |
| `AMBA_Low_Power_Interface.pdf` | LPI | IHI 0068 | Q-Channel / P-Channel 低功耗接口 |

## 来源

- 主要 PDF 来自 GitHub 镜像仓库 [qinfen1127/AMBA4](https://github.com/qinfen1127/AMBA4)（`AMBA_protocol/` 目录）
- `AMBA_Low_Power_Interface.pdf`（IHI 0068）来自 ARM 官方文档服务 [developer.arm.com/documentation/ihi0068](https://developer.arm.com/documentation/ihi0068/d)
